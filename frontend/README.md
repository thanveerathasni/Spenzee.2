# Spenzee Frontend

Production-oriented React foundation using feature modules, Redux Toolkit, typed API boundaries, route guards, and shared infrastructure.

## Setup

1. Copy `.env.example` to `.env` and set `VITE_API_BASE_URL`.
2. Run `npm install`.
3. Run `npm run dev`.

Feature pages are intentionally not implemented yet; route slots, guards, service contracts, and module boundaries are ready for them.
